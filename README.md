# CUDI - Personal KI

CUDI ist ein persönlicher KI-Assistent (Künstliche Intelligenz) Projekt.

## Über das Projekt

CUDI steht für einen personalisierten KI-Assistenten, der entwickelt wird, um intelligente Unterstützung zu bieten.

## Projektziele

- Entwicklung eines persönlichen KI-Assistenten
- Bereitstellung intelligenter Funktionen
- Benutzerfreundliche Interaktion

## Technologie-Stack

Das Projekt ist für Python vorbereitet, wie die `.gitignore` Konfiguration zeigt.

## Status

Das Projekt befindet sich in der Anfangsphase der Entwicklung.

## Getting Started

### Voraussetzungen

- Python 3.x
- pip (Python Package Manager)

### Installation

```bash
# Repository klonen
git clone https://github.com/Poso47/CUDI.git
cd CUDI

# Virtuelle Umgebung erstellen (empfohlen)
python -m venv venv
source venv/bin/activate  # Auf Windows: venv\Scripts\activate

# Abhängigkeiten installieren (wenn vorhanden)
# pip install -r requirements.txt
```
